# Context

## reMarkable

- Device: reMarkable 2
- OS: Codex Linux
- xochitl: 3.28.0.169
- SSH: Dropbear
- USB IP: `10.11.99.1`

## Windows

- USB network IP: `10.11.99.14`
- Print file: `C:\reMarkable\print.prn`
- Printer name: `reMarkable`

## SSH

First SSH into the reMarkable:

`ssh root@10.11.99.1`

Verify the USB IP:

`ip addr`

The USB network must expose:

`10.11.99.1`

## Upload API

The reMarkable web interface accepts PDFs at:

`http://10.11.99.1/upload`

The upload is:

`POST /upload`

using multipart field:

`file`

Successful uploads appear in the reMarkable library without restarting xochitl.

## Working flow

1. Windows prints to `reMarkable`.
2. Microsoft Print to PDF writes:
   `C:\reMarkable\print.prn`
3. `remarkable-print.ps1` detects the file.
4. PowerShell uploads it to:
   `http://10.11.99.1/upload`
5. The PDF appears in the reMarkable library.

## Important

Do NOT:

- restart xochitl
- use `printer.arm -restart`
- modify OTG configuration
- replace the working `/upload` method
- use the old TCP/9100 relay as the final solution

The `.prn` file is actually a PDF generated by Microsoft Print to PDF.
